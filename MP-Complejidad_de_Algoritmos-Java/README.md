Ejecucion desde VS Code:
- Desde src hacer "javac *.java NumeroHexagonales/*.java".
- Posteriormente "java NumeroHexagonales.Main" para poner en ejecucion el "Main.java" que se encuentra dentro de "NumeroHexagonales"

Ejecucion desde Eclipse:
- Darle al boton de ejecutar (Run Main) estando en el archivo Main.java de Eclipse.
