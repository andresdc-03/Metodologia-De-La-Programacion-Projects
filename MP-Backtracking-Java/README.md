Ejecucion desde VS Code:
- Cambiar la ruta del fichero de entrada "ArchivoBecas" a la ruta "BECAS.dat"
- Desde el terminal, desde src hacer "javac *.java BecasDeColavoracion/*.java".
- Posteriormente "java BecasDeColavoracion.Main" para poner en ejecucion el "Main.java" que se encuentra dentro de "BecasDeColavoracion"

Ejecucion desde Eclipse:
- Cambiar la ruta del fichero de entrada "ArchivoBecas" a la ruta "src/BECAS.dat"
- Darle al boton de ejecutar (Run Main) estando en el archivo Main.java de Eclipse.
