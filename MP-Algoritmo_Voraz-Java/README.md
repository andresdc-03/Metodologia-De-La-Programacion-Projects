Ejecucion desde VS Code:
- Desde el terminal, desde src hacer "javac *.java SoladoDeBaldosas/*.java".
- Posteriormente "java SoladoDeBaldosas.Dominio" para poner en ejecucion el "Dominio.java" que se encuentra dentro de "SoladoDeBaldosas"

Ejecucion desde Eclipse:
- Darle al boton de ejecutar (Run Main) estando en el archivo Main.java de Eclipse.
