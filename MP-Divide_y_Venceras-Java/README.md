Ejecucion desde VS Code:
- Cambiar la ruta del fichero de entrada "FICHERO_DATOS" a la ruta "NInversiones/Data/InversionesTest.dat"
- Desde src hacer "javac *.java NInversiones/*.java".
- Posteriormente "java NInversiones.Main" para poner en ejecucion el "Main.java" que se encuentra dentro de "NInversiones"

Ejecucion desde Eclipse:
- Cambiar la ruta del fichero de entrada "FICHERO_DATOS" a la ruta "src/NInversiones/Data/InversionesTest.dat"
- Darle al boton de ejecutar (Run Main) estando en el archivo Main.java de Eclipse.
